  "success": true,

  "success": false,
  "error": {
    "code": "VALIDATION_ERROR",
    "message": "Human-readable description",
    "details": [ ... ]       // field-level errors where applicable
  }
}

1.4 Pagination
All list endpoints support: ?page=1&limit=20. Default: page=1, limit=20. Maximum limit=100. Response includes meta.total, meta.totalPages, meta.page, meta.limit.
1.5 Soft Delete Behaviour
All GET list endpoints exclude soft-deleted records (WHERE deleted_at IS NULL) by default. Admin-only endpoints may include ?includeDeleted=true to surface deleted records.
1.6 RBAC Enforcement
Role-based access is enforced at both the NestJS guard layer and the database query layer. A Manager cannot access another Manager's clients or audits. An Auditor cannot access audits not assigned to them. A Client cannot access other clients' data.
