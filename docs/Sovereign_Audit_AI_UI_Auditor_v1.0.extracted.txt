3. Audit Scope Workspace
SCR-AUD-002 — Audit Scope Workspace
Screen ID
SCR-AUD-002
Route
/auditor/audits/:auditId
Persona
Auditor
Purpose
Main working screen. Shows assigned scope line items grouped by BU. Auditor navigates, fills responses, uploads documents, raises exceptions.
Layout
Two-panel layout. Left sidebar (250px, collapsible): BU list with per-BU progress rings. Main area: line items list for selected BU. Each line item is a collapsible card. Top header shows audit name, client, overall progress, and Submit to Manager button (enabled only when eligible).

### Compliance Score Input (New)
  - 1–5 segmented selector shown on each line item submission form
  - Label: "Compliance Score (1 = Non-Compliant, 5 = Fully Compliant)"
  - Required field — submission blocked without score
  - Hover labels: 1=Non-Compliant, 2=Mostly Non-Compliant, 3=Partially Compliant,
    4=Mostly Compliant, 5=Fully Compliant

### RESTRICTIONS
  - Auditors have NO visibility of aggregate compliance scores, percentages,
    or weighted contributions anywhere in the auditor portal
  - The per-item score selector is the only score-related UI element for auditors
