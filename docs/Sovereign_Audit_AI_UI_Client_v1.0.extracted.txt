Landing page. Real-time status of all active audits + summary of last completed audit. Designed for senior executive consumption.

Hero KPI row (4 cards). Below: two-column layout. Left (60%): Active Audits list with status cards. Right (40%): Pending Actions panel (clarifications + report reviews needing attention). Clean, data-forward design.

Clean, search-focused layout. Large search input centred on page (similar to a chat/search interface). Below: search history (previous queries in current session). Results appear below the input after each search. Suggested prompts shown on empty state.
