### Weightage Management (New)
Components added to ScopeItemsTable:
  - WEIGHTAGE column: inline editable percentage input per line item
  - Total Weightage summary bar: shows running sum, colour-coded (green=100%, amber=partial, red=0%)
  - "Distribute Equally" button: auto-assigns equal weightage across all items
  - Warning banner: shown when weightages ≠ 100% (blocks report generation)

Validation:
  - All weightages must sum to exactly 100% (±0.01 tolerance)
  - Report generation blocked if validation fails
  - Toast shown on successful bulk weightage save

Chronological tamper-proof log of all interactions within an audit: manager↔auditor and manager↔client.
Layout
Timeline view. Each entry is a timestamped card. Filter toggles at top: All | Manager-Auditor | Manager-Client | System Events. Entries are read-only — no editing or deletion.
